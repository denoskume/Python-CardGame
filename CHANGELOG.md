# Changelog

- Shared desktop/browser interface with responsive geometry and cached typography.
- Three difficulty levels, persistent sound settings, help and keyboard/touch controls.
- Full-stake affordability checks, frozen bets, exact-deadline handling and single settlement.
- Correct net-profit statistics and persistent profile balances.
- Pause/focus and resize handling that preserves logical card positions.
- Validated local persistence with atomic desktop writes and session fallback.
- Browser loading/retry feedback and branch/PR validation before Pages delivery.
- V2.0 published live with GitHub Pages: https://denoskume.github.io/Python-CardGame/
